## ✍️ [digit_recognizer/](digit_recognizer/)  
A handwriting-based digit recognizer built with **TensorFlow/Keras** using the **MNIST dataset**.  
Includes:  
- [draw.py](digit_recognizer/draw.py) — draw a single digit on a canvas for prediction  
- [draw_multi_digits.py](digit_recognizer/draw_multi_digits.py) — draw multiple digits at once  
- [train_model.py](digit_recognizer/train_model.py) — train the CNN model and save as [mnist_cnn_model.h5](digit_recognizer/mnist_cnn_model.h5)
